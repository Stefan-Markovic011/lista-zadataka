# lista-zadataka

Jednostavna web aplikacija za dodavanje i prikaz zadataka. Projekat je napravljen kao vežba za rad sa HTML-om, CSS-om i JavaScript-om.

Aplikacija je dostupna na:

https://stefan-markovic011.github.io/lista-zadataka/

Funkcionalnosti

Dodavanje novih zadataka
Unos zadatka preko input polja
Prikaz zadataka na stranici
Jednostavan i pregledan korisnički interfejs

Tehnologije

HTML5
CSS3
JavaScript
GitHub Pages
